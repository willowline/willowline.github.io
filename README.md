# 윌로우라인 홈페이지 — 페이지 분리 버전

- 자연눈썹: https://willowline.github.io/?v=split-theme11
- 남자눈썹: https://willowline.github.io/men.html?v=split-theme11
- GitHub: https://github.com/willowline/willowline.github.io

## 최신 파일

- index.html: 따뜻한 아이보리·올리브의 자연눈썹 메인.
- men.html: 그레이시 딥그린·쿨그레이 남자눈썹 페이지.
- site.css: 두 페이지의 공통 레이아웃·개별 테마.
- site.js: 메뉴·사례 분류·더보기·사진 확대·모션·영상 제어.
- 이미지 JPG, hero-studio.mp4, hero-studio-poster.png: 실제 자료 및 제공된 브랜드 영상.
- PRD.md / VERIFICATION.md / PHOTO-SOURCES.md: 기획·검수·출처.

GitHub main 루트에 HTML·CSS·JS·추가 이미지를 함께 올려 배포합니다. 데이터 서버는 없습니다.

두 페이지의 상단 카테고리로 이동하고 모바일에서도 두 메뉴를 바로 볼 수 있습니다. 자연눈썹에는 전체·여성·남성 사례 분류와 더보기가 있습니다. 모든 사례는 확대할 수 있습니다.

이벤트는 자연눈썹 정상가 16만 원 → 13만 원입니다. 리터치 일정·포함 범위·가격과 세부 예약 조건은 상담 안내입니다. 다른 매장의 가격과 경력·후기·리터치 조건을 사용하지 않습니다.

네이버는 플레이스 이동, 상담·예약 문의는 기존 카카오톡 채널로 연결합니다. 대표 검토 기간 noindex 설정을 유지합니다. 과거 hero.jpg와 brow-detail.jpg는 보관 자료입니다.
