# 윌로우라인 · WILLOW LINE

**홈페이지: https://willowline.github.io/**

윌로우라인 GitHub 조직의 공식 홈페이지입니다. GitHub Free와 GitHub Pages로 배포하며, 홈페이지 주소에 개인 계정명이 표시되지 않습니다. Netlify 등 별도 호스팅을 사용하지 않습니다.

## 홈페이지 구성

자연광 중심 첫 화면 → 고객의 세 가지 걱정 → 시술 전후 사례 4개 → 아버지 이야기와 디자인 기준 → 4단계 상담·시술 과정 → 가격 → FAQ → 매장·위치 → 상담·예약.

사용자 피드백에 따라 첫 화면의 눈썹 사진 액자를 제거하고, 지나치게 축약했던 원장님 이야기와 상담 과정의 설명을 다시 보강했습니다. 기존 문구와 구성을 유지하고 그레이시 딥그린·쿨그레이로 색감을 조정했습니다. 첫 화면 오른쪽에는 제공받은 인물 브랜드 영상을 무음 반복 재생합니다. 영상 일시정지와 재생 버튼을 제공합니다.

## 화면 동작

부드러운 첫 등장·스크롤 등장 효과를 제공하고 기기의 동작 줄이기 설정을 존중합니다. 네이버 플레이스·카카오톡 상담 버튼은 PC·모바일 모두 하단 고정이며 새로고침하면 맨 위에서 시작합니다.

## 첫 화면 영상

- `hero-studio.mp4`: 사용자 제공 브랜드 무드 영상, 실제 시술 사례 아님.
- `hero-studio-poster.png`: 영상에서 추출한 로딩·정지 화면.
- 화면 밖에서는 재생을 멈추고 기기의 동작 줄이기 설정을 존중합니다.

## 파일 및 운영

- `index.html`: 페이지 문구·스타일·사진 확대·FAQ
- `hero.jpg`: AI 생성 브랜드 무드 이미지. 실제 매장·고객·시술 사진이 아닙니다.
- `result-01.jpg`~`result-04.jpg`: 실제 시술 사례 (brow-detail.jpg는 현재 미사용)
- `consultation.jpg`, `studio.jpg`: 실제 상담과 매장 사진
- `PHOTO-SOURCES.md`: 사진 출처 기록
- `favicon.svg`: 브랜드용 선형 식물 심볼
- `robots.txt`: 대표 검토 기간 검색 제외 요청
- `.nojekyll`: 정적 파일 게시
- `PRD.md`: 기획 기준과 변경 이력
- `VERIFICATION.md`: 검수 기록

배포 원본은 `main` 브랜치 루트입니다. 파일 변경을 커밋하면 GitHub Pages가 갱신됩니다. 운영자 계정은 조직 관리자 권한으로 관리하며 별도 회원·결제 서버는 없습니다.

## 반영 정보

자연눈썹 정상가 160,000원 → 이벤트 130,000원, 콤보 200,000원, 수지 190,000원, 헤어스트록 250,000원, 입술 280,000원. 확인되지 않은 무료 리터치·추가 할인·SMP·잔흔 제거는 노출하지 않았습니다. 네이버는 플레이스 이동, 상담·예약 문의는 카카오톡 채널로 연결합니다.

사용자가 허용한 윌로우라인 자료 폴더의 실제 사진을 반영했습니다. 다른 매장의 후기·행사·경력은 차용하지 않았습니다.

대표 검토 기간에는 noindex 및 robots 차단을 유지합니다. 이는 접근 제한이 아니며 홈페이지 주소로 누구나 열람할 수 있습니다.
