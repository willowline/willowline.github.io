## 현재 버전 v13

통합 영상 첫 화면 → 실제 시술 사례(남성 2개·여성 2개) → 자연눈썹 13만 원 이벤트 → 디자인 기준 → 상담 과정 → 원장님 이야기 → 가격·FAQ → 위치·예약.

딥그린·쿨그레이와 단정한 고딕체로 구성했습니다. 사용자 제공 영상은 브랜드 무드 영상이며 실제 시술 사례와 구분해 표시합니다. 영상은 무음 반복 재생, 일시정지·재생, 화면 밖 자동 정지, 동작 줄이기 설정을 지원합니다.

## 수정·배포

- index.html: 본문·CSS·JS를 포함한 정적 홈페이지.
- hero-studio.mp4 / hero-studio-poster.png: 첫 화면 영상과 포스터.
- result-01~04.jpg: 실제 전후 사례.
- consultation.jpg / studio.jpg: 실제 상담·매장 사진.
- PRD.md / VERIFICATION.md / PHOTO-SOURCES.md: 기획·검수·사진 출처.
- .nojekyll / robots.txt / favicon.svg: 게시·검색·아이콘 설정.
- hero.jpg와 brow-detail.jpg는 과거 버전용 보관 자료로 현재 화면에 사용하지 않습니다.

GitHub main 브랜치 루트에 변경 파일을 올리면 Pages가 배포됩니다. 상담은 카카오톡, 위치는 네이버 플레이스로 연결합니다. 네이버 예약 URL이 확인되지 않아 플레이스를 예약 버튼으로 표기하지 않습니다.

자연눈썹 정상가 160,000원 → 이벤트 130,000원. 무료 리터치·행사 기간·정원 등 확인되지 않은 조건은 표시하지 않습니다. 현재는 대표 검토용 noindex를 유지합니다.
